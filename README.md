# WEB-Tasar-m-WEB-Design-
Web tasarımı konusunda temel HTML, CSS ve JavaScript bileşenlerini içeren örnek kodları ve projeleri barındırmaktadır. Web teknolojilerinin yapısını anlamaya yönelik pratik kodlar ve açıklamalar sunarak, hem başlangıç seviyesi hem de ileri düzey kullanıcılar için kaynak olmayı hedeflemektedir.
